# GitHub Actions do zero ao CI/CD

<img src="https://octodex.github.com/images/jetpacktocat.png" align="right" height="200px" />

_Automatize um jogo da memória em React + Vite enquanto aprende
GitHub Actions na prática._

## Boas-vindas

- **Para quem é**: pessoas desenvolvedoras que querem automatizar testes, build e
  deploy com GitHub Actions.
- **O que você vai aprender**: `workflows`, `jobs`, `runners` e `steps`; CI com
  `strategy.matrix`; `workflow artifacts`; `reusable workflows`; e AI com
  `GitHub Models`.
- **O que você vai construir**: uma pipeline de CI/CD completa para o **OctoMatch**,
  um jogo da memória com o Octodex.
- **Pré-requisitos**: noções de Git e GitHub.
- **Duração**: aproximadamente 2 horas.

Neste treinamento você vai, passo a passo:

1. Criar o seu primeiro workflow (`event`, `job`, `runner`, `step`).
2. Montar uma pipeline de CI que roda os testes em uma `matrix` de Node.
3. Publicar o relatório de cobertura como workflow artifact.
4. Extrair os quality checks para um reusable workflow.
5. Fazer triagem automática de issues com GitHub Models.

## Como começar

1. Use este repositório como **template** para criar o seu próprio.
2. Dê ~20 segundos para a preparação do primeiro passo e atualize a página.
3. Acompanhe cada passo pela **issue** criada automaticamente.
